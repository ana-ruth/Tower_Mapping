# Tower Mapping

A full-stack web application designed to visualize geospatial data for telecommunications teams, streamlining site planning and decision-making.

## Features
- Report generation with cellular tower layouts using **Google Maps API** and **Python-docx**.
- User-friendly interface built with **Next.js** for seamless navigation and data interaction.
- Backend integration with **FastAPI** to process and serve geospatial data.

## Technologies Used
- Frontend: Next.js, TypeScript
- Backend: FastAPI, Python
- Data Visualization: Google Maps API


## Future Improvements
- Enhance data filtering options for users.
- Add support for exporting geospatial data in multiple formats.
